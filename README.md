# Базовый частотный словарь



Команда исследует текст и хочет понять, какие слова в нём встречаются чаще всего. Для этого нужно составить частотный словарь — напротив каждого слова указать число его появлений.

## Задача

Дана последовательность из `n` слов, записанных через пробел. Подсчитайте, сколько раз встречается каждое слово.

Для хранения результата используйте `HashMap<String, usize>`, где ключ — слово, а значение — количество его появлений. Слова считаются одинаковыми только при полном совпадении написания. Все слова во входных данных записаны в нижнем регистре.

**Дополнительное задание:** решите задачу в одну строку.

## Интерфейс для тестов

Реализуйте и экспортируйте из `src/lib.rs` функцию:

```rust
pub fn word_frequencies(input: &str) -> std::collections::HashMap<String, usize>
```

Пустая строка и строка из пробелов соответствуют пустой последовательности слов. Несколько пробелов между словами не образуют пустых слов.

## Рекомендации

- Перед началом работы самостоятельно создайте Rust-проект в этой папке командой `cargo init --name task3_4_template`.
- Проверьте подсчёт для повторяющихся слов, разных слов и пустой последовательности.
- Автоматические тесты находятся в `tests/assignment.rs`; запускайте их командой `cargo test`.

- После реализации запустите `cargo fmt` и `cargo check`.
